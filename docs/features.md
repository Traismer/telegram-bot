# Функциональность

## Команды

- `/start` - приветственное сообщение
- `/help` - список доступных команд
- `/news` - получение последних новостей с Хабра

## Кнопки

- `Start` - приветственное сообщение
- `News` - получение последних новостей с Хабра

## Новости

Бот получает новости с Хабра и отображает:
- Заголовок новости
- Автора
- Количество просмотров
- Ссылку на новость
- Изображение (если есть)
